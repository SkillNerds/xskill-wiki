# 手改技能后自动上传

## 一句话

连上团队后，你直接改本机的技能文件。后台会发现这些改动，自动传到服务器上「属于你的草稿」，供下一轮自动改写参考。你不用再敲一条上传命令。

## 什么时候用

- 你是熟悉业务的人，觉得某条技能写得不对，打开文件改几句更准
- 你希望改动能被系统学到，但不要马上变成全队正式版
- `xskill connect` 已经在后台跑着

## 怎么用

1. 确认客户端常驻：

```bash
xskill status
```

2. 打开本机技能目录里的 `SKILL.md`（一般在 `~/.xskill/skill/<技能名>/`），直接改。
3. 保存后等一会儿。客户端会把未吸收的手改传到服务器。
4. 这些改动进的是你的个人草稿，**不会直接覆盖全队正在用的正式版**。

## 和相近命令的差别

| 命令 | 差别 |
| --- | --- |
| `xskill upload` | 你主动打包一份完整技能，放到共享目录给人搜。手改自动上传是「改动草稿」。 |
| `xskill generate` | 你用一句话让服务器改。手改是你自己动文件。 |
| `xskill import` | 用一份完整目录替换/收编正式技能。手改自动上传不是收编。 |

## 注意

- 没开 `connect` 时，改文件只留在你电脑上，服务器看不到。
- 草稿到正式版，还要经过系统后续的改写和对比；用着更好才会留下。
- 个别助手（例如 OpenClaw）改的是安装副本。客户端会尽量把那边的修改同步回来再上传；如果你改完发现没传上去，看 `xskill status` 是否还在跑。
