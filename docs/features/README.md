# 特性说明放这里

每位新同学都可以给 xskill 补一页命令说明。

1. 复制 [`_template.md`](_template.md) 为 `<命令>.md`
2. 按模板用白话写完
3. 把同一内容接到网站：`wiki.html` 加小节，`i18n.js` 补中英对照
4. 目录里加锚点，推到 `main` 或开 Pull Request

已经写好的范例：

- [generate](generate.md)
- [upload](upload.md)
- [import](import.md)
- [手改自动上传](rewrite-auto-upload.md)

网站上对应的入口：[https://xskill.wiki/wiki.html#features](https://xskill.wiki/wiki.html#features)
