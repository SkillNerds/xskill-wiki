# xskill import

## 一句话

把已经存在的技能目录收进 xskill 自己的技能库，装到你的编程助手里。可以收一个技能，也可以收一整层父目录里的多个技能。

## 什么时候用

- 你从别处拿到了技能文件夹，想让 xskill 管起来（有版本、能更新）
- 本机助手目录里已经有技能，想收编进 xskill，而不是继续当一份孤立文件
- 团队模式下，想把这份技能交到服务器的正式技能库

## 怎么用

```bash
# 一个技能目录（里面有 SKILL.md）
xskill import ./my-skill

# 父目录里有多份技能
xskill import ./skills-folder
```

单人模式：收进本机技能库，并装到已检测到的编程助手。

已 `connect` 的团队成员：会传到服务器的正式技能库，再把这一版同步回你的电脑并装好。

## 和相近命令的差别

| 命令 | 差别 |
| --- | --- |
| `xskill upload` | upload 放到共享目录，等人搜索下载。import 是收进正式技能库。 |
| `xskill generate` | generate 按一句话新建或改写。import 用的是你已经有的文件。 |

## 注意

- 从编程助手自己的技能目录（例如 `~/.claude/skills/`）去 import 时，会提示你：那是助手在用的副本，收编后请以 xskill 里的那份为准。
- 如果这个技能已经在库里，import 会更新正式版。原来还在试用中的对比版本会保留，避免正在进行的对比被打断。
- 你本地没提交的修改会被拷到备份目录，本机换成这次导入的版本，避免改丢。
- 团队模式下不要把它理解成「随便覆盖全队」：服务器仍按正式技能库的规则收纳；你的身份需要已经 `connect`。
