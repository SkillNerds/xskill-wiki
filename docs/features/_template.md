# xskill \<命令名\>

> 复制本文件为 `docs/features/<命令>.md`。用白话写，一屏看完。命令本身保持英文。

## 一句话

它帮你做成哪一件具体的事。

## 什么时候用

- 场景 A
- 场景 B

不要写「什么时候不用」的空话；有真正会踩的坑再写「注意」。

## 怎么用

```bash
xskill <命令> ...
```

用真实能跑的例子，不要写假参数名堆砌。

## 和相近命令的差别

| 命令 | 差别 |
| --- | --- |
| `xskill 甲` | … |
| `xskill 乙` | … |

## 注意

- 需要先 `xskill connect` 吗？
- 会不会改到全队正式技能？
- 失败时人能看懂的提示是什么？
