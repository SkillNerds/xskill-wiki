# xskill generate

## 一句话

你已经连上团队之后，用一句话说清楚想要的技能，服务器马上帮你写，或改已有的技能。

## 什么时候用

- 你知道该有一条技能，但不想自己从零写 `SKILL.md`
- 现有技能不够用，想按你的要求改一版
- 希望生成时优先参考某几位同事的经验

## 怎么用

先连上团队（或公网实例），然后：

```bash
xskill generate "把处理发票报销的步骤写成技能"
```

只想参考某些人的会话时，带上工号或用户名（逗号分隔）：

```bash
xskill generate --name alice,bob "把他们处理发布失败的办法写成技能"
```

命令会打印进度。完成后会告诉你生成了哪些技能，并尽量钉到你的推荐列表里，方便你马上用。

## 和相近命令的差别

| 命令 | 差别 |
| --- | --- |
| `xskill upload` | 你已经有一份写好的技能文件夹，发给大家搜。generate 是让服务器代写。 |
| `xskill import` | 把现成技能收进正式技能库。generate 是新建或改写。 |
| 手改自动上传 | 你自己改文件。generate 是你说话、系统改。 |

## 注意

- 必须先 `xskill connect`。没连上会提示连不上服务器。
- 服务器版本太旧时会明确说不支持 generate，需要管理员升级。
- 任务可能排队。看到「仍在排队」是正常的，等席位即可。
- 写出来的技能会进入团队技能库；请不要在指令里写密钥、密码、身份证号。
