What xskill Does

xskill automatically distills agent execution trajectories into reusable Skills.

Core Capabilities

  • Trajectory → Skill pipeline — Watch agent sessions, split them into single-intent Atoms, route each Atom to its Skill, and rewrite the Skill when enough material accumulates.
  • Team sharing — One person solves a problem; the distilled Skill is automatically available to every teammate. No one writes documentation or copies files around.
  • Git-versioned evolution — Every Skill is its own git repository. Every change is traceable and linked back to the trajectories that triggered it.
  • Canary A/B + UX Score — New Skill versions are tested on a controlled share of live traffic. The version with a higher UX score (1–10) wins; the loser is discarded automatically.

xskill 做什么

xskill 自动将 Agent 执行轨迹蒸馏为可复用的 Skill。

核心能力

  • 轨迹 → Skill 管线 — 监听 Agent 会话，按单一意图切成 Atom，将每个 Atom 路由到对应 Skill，攒够素材后重写 Skill。
  • 团队共享 — 一个人解决了问题，蒸馏出的 Skill 自动对全团队可用。不需要写文档，也不需要手动拷贝文件。
  • Git 版本化进化 — 每个 Skill 就是一个独立 git 仓库。每次变更都可追溯，并关联到触发它的执行轨迹。
  • 灰度 A/B + UX 评分 — 新版本 Skill 在一部分真实流量上做受控测试。UX 评分（1–10）更高的版本胜出，输的版本自动淘汰。
