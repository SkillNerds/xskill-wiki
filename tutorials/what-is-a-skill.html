What is a Skill

A Skill is a versioned, reusable instruction file that an AI agent can load and execute automatically.

More Than a Prompt Snippet

Unlike a simple prompt snippet or a RAG document, a Skill is:

  1. Stored as a git repository with full version history — every change is tracked and reversible.
  2. Structured with metadata (triggers, scope, dependencies) so the agent knows when and how to apply it.
  3. Continuously improved through A/B testing and UX scoring — bad versions are automatically discarded, good ones survive.

The Standard Format

The standard format is SKILL.md — a markdown file that lives in a skill directory alongside any supporting scripts or reference files. Each skill directory is its own git repository, giving it independent version history.

什么是 Skill

Skill 是一种带版本控制的、可复用的指令文件，AI agent 能自动加载并执行它。

不只是一段 Prompt

与简单的 prompt 片段或 RAG 文档不同，一个 Skill 具有以下特征：

  1. 以 git 仓库存储，拥有完整版本历史——每次变更都可追踪、可回退。
  2. 带有结构化元数据（触发条件、作用范围、依赖关系），agent 知道何时以及如何应用它。
  3. 通过 A/B 测试和 UX 评分持续改进——差的版本自动淘汰，好的版本留存。

标准格式

标准格式是 SKILL.md——一个 markdown 文件，存放在技能目录中，旁边可以有辅助脚本或参考文件。每个技能目录本身就是一个独立的 git 仓库，拥有独立的版本历史。
