Cache Hit Rate

Derive the formulas for cache hit rate in both modes, then visualize how hit rate evolves over a multi-turn conversation.

Agent Mode Formula

In Agent mode, messages are strictly appended. At turn $n$, the total input is the full history. The only "new" tokens (cache miss) are the user message $U_n$ just added:

$$\text{HitRatio}_{\text{agent}}(n) = 1 - \frac{U_n}{S_0 + U_0 + \sum_{i=1}^{n-1}(R_i + C_i + T_i + TR_i + U_i) + U_n}$$

As $n$ grows, the denominator grows much faster than the numerator ($U_n$ stays roughly constant), so hit rate monotonically approaches 100%.

Direct Chat Mode Formula

In Direct Chat, the server strips reasoning ($R_i$) from history. Additionally, the last assistant response $C_{n-1}$ is freshly appended (wasn't in the previous request). So the miss includes both $C_{n-1}$ and the new $U_n$:

$$\text{HitRatio}_{\text{chat}}(n) = 1 - \frac{C_{n-1} + U_n}{S_0 + U_0 + \sum_{i=1}^{n-1} C_i + \sum_{i=1}^n U_i}$$

Notice: longer model answers ($C_{n-1}$) directly reduce the hit rate. Agent mode doesn't have this problem because $C_{n-1}$ was already in the previous request.

Interactive Visualization

缓存命中率

推导两种模式下缓存命中率的公式，然后可视化展示命中率在多轮对话中的演变。

Agent 模式公式

Agent 模式下，消息是严格追加的。在第 $n$ 轮，总输入是完整历史。唯一的"新" token（缓存未命中）是刚追加的用户消息 $U_n$：

$$\text{HitRatio}_{\text{agent}}(n) = 1 - \frac{U_n}{S_0 + U_0 + \sum_{i=1}^{n-1}(R_i + C_i + T_i + TR_i + U_i) + U_n}$$

随着 $n$ 增大，分母增长远快于分子（$U_n$ 大致不变），所以命中率单调趋近 100%。

直聊模式公式

直聊模式下，服务端剥离推理（$R_i$）。而且上一轮的 assistant 回复 $C_{n-1}$ 是新追加的（上一次请求中没有）。所以未命中包含 $C_{n-1}$ 和新的 $U_n$：

$$\text{HitRatio}_{\text{chat}}(n) = 1 - \frac{C_{n-1} + U_n}{S_0 + U_0 + \sum_{i=1}^{n-1} C_i + \sum_{i=1}^n U_i}$$

注意：模型回答越长（$C_{n-1}$ 越大），命中率越低。Agent 模式没有这个问题，因为 $C_{n-1}$ 已经在上一次请求中了。

Four Conclusions

  1. Hit rate monotonically increases — As turns grow, the cached prefix dominates. Both modes trend toward 100%, but Agent mode gets there much faster.
  2. Context compression causes sudden drops — If you summarize old messages to save context window, the entire prefix changes and hit rate drops to near 0% (then rebuilds).
  3. Direct Chat: longer answers → lower hit rate — Each new C is a cache miss. If C is 1000 tokens vs 100 tokens, the difference is dramatic.
  4. Agent mode hit rate is significantly higher — Because reasoning (R) is preserved in the prefix, the only miss per turn is the tiny U. In Direct Chat, each turn misses both C and U.

四个结论

  1. 命中率单调递增——随着轮次增加，缓存前缀占比越来越大。两种模式都趋向 100%，但 Agent 模式到达得快得多。
  2. 上下文压缩导致突然下降——如果你为了省 context window 而对旧消息做摘要，整个前缀都变了，命中率跌到接近 0%（然后重新积累）。
  3. 直聊模式：回答越长 → 命中率越低——每个新的 C 都是缓存未命中。C 是 1000 token 和 100 token 的差别巨大。
  4. Agent 模式命中率显著更高——因为推理（R）保留在前缀中，每轮唯一的未命中只有很小的 U。直聊模式每轮都要未命中 C 和 U。
